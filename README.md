# NoeCode

Bootstrap implementation of the Noe programming language.

Current milestone: Phase 3/8 foundation — lexer, parser, type checker, NIR, optimizer, interpreter, native backend scaffolding, linker driver, package manager, formatter, test runner, and language server scaffolding.

Noe source files use `.noe`. Project manifests use `project.noe`. No TOML is used by Noe projects.
